Overview · 概览

参评对象

cpq-configure-price-quote 金蝶星空

  • 面向金蝶云AI星空平台的通用 CPQ 框架
  • 五步流程：需求确认 → 产品配置 → 定价比价 → 折扣毛利 → 报价输出
  • 强依赖 ERP/MCP，定义了 32 个工具接口
  • 多方案并行、配置快照不可变、审批流转
  • 定位：企业级蓝图，无可执行代码

sloth-cpq-eido 多行业CPQ

  • 面向装备/机加/电子/汽车零部件的智能报价引擎
  • 十步工作流：正向/反向/多行项/折扣/审批/快照/版本管理
  • 6 个 MCP 工具 JSON Schema + 金蝶 265行字段映射（已落地）
  • 四级数据降级：MCP → CSV → 对话 → 默认值
  • 定位：可独立运行、可渐进集成 ERP 的端到端报价引擎

Dimension 2 · 工程实现

Dimension 3 · 领域知识深度

成本模型与行业壁垒

cpq-configure-price-quote

  • 成本模型：六维成本（材料/人工/制造/运输/场地/非标）
  • 定价路径：价目表 → 成本加成 → 手工询价 → 参数规则
  • 折扣策略：四层折扣 + 60%底线
  • 约束规则：五种约束优先级（P1范围→P5数量）
  • 行业覆盖：单行业（金蝶星空通用）

sloth-cpq-eido

  • 成本模型：三级费率 + 系数矩阵 + 学习曲线 + 质保准备金 + 外汇风险 + 材料锁价
  • 费率结构：直接人工 → 含间接费(120-180%) → 全负荷费率(+20-30%)
  • 学习曲线：焊接85%、机加工80%、SMT 90%、冲压88%
  • 质保准备金：覆盖12/18/24/36月 × 4级复杂度 × 4级工况
  • 行业覆盖：四行业（装备/机加/电子/汽车零部件 511行知识库）
结论：sloth 在装备制造领域有明显知识壁垒，cost-calculation-guide.md 可直接作为成本工程师培训教材。
