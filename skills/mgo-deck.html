Why 深拓

B2B SaaS 市场部，每天都在面对什么？

✍

内容生产慢

一篇竞品对比文章需要市场人折腾一整天，从调研、撰写到排版，重复性格式劳动占满日程。

🗃

线索质量差

活动收集的 500 条线索，清洗后只剩 50 条有效，MQL → SQL 转化率低，销售抱怨"线索太水"。

📶

渠道各自为政

公众号、知乎、小红书、头条各发各的，内容不统一、数据不打通，无法归因哪个渠道真正带来成交。

🚫

合规风险高

广告法、个保法、行业监管政策不断变化，内容发布前缺乏系统校验，一不小心就踩红线。

Architecture

1+7 父子架构，一个入口调度全链路

深拓采用指挥官模式：父 Skill 负责意图识别、风控校验、知识库注入、模块调度和跨模块上下文传递。子模块 A-G 为无状态执行器，各自拥有独立角色定义、工作流和输出规范。

B活动与项目指挥

活动策划、执行总控表、预算管理、供应商对比、跨模块进度监控

活动策划流程

  • 输入活动目标与预算，AI 自动生成策划方案
  • 生成执行总控表：里程碑、责任人、交付物、风险点
  • 供应商对比矩阵：报价、口碑、交付能力评分
  • 跨模块进度监控：内容产出 → 渠道发布 → 线索收集 → 销售跟进

常用活动类型

  • 线下沙龙 / 发布会
  • Webinar / 线上直播
  • 联合品牌活动
  • 客户答谢 / 用户大会

C市场情报中心

竞品动态监控、行业趋势追踪、客户需求变迁分析、Battle Card 生成

🔍

竞品监控

追踪竞品推进阶段、销售代表、报价策略、实施配置、关系深度

📈

趋势追踪

行业政策、技术趋势、客户需求变迁，自动发现品类机会

🛡

Battle Card

自动生成竞品作战卡：对手优势/劣势、应对话术、最佳案例

情报驱动内容

当用户说"写篇针对竞品A的对比文章"时，系统自动先调用情报中心拉取竞品A最新动态，再基于最新数据撰写内容，确保内容时效性和准确性。

D线索培育与转化引擎

线索清洗打分、培育序列编排、销售赋能、市场-销售双向反馈

HABC 四级评分体系

  • H 级（Hot）：高意向，立即转销售
  • A 级（Active）：有需求，进入快速培育
  • B 级（Browsing）：有兴趣，长期培育
  • C 级（Cold）：潜在匹配，低频触达

销售赋能输出

  • 每条 H/A 级线索自动生成销售情报卡
  • 包含：线索来源、兴趣点、互动历史、最佳跟进时机、推荐话术
  • 市场-销售双向反馈闭环：销售跟进结果回写，优化培育策略

G增长度量与实验

北极星指标看板、归因分析、A/B 实验框架、ROI 复盘、预算建议

北极星指标看板

  • MAU / 激活率 / 付费转化率 / NRR（净收入留存率）
  • CAC / LTV / Payback Period
  • 渠道 ROI 对比，自动识别高效渠道

A/B 实验框架

  • 假设 → 实验设计 → 样本量计算 → 执行 → 结果分析
  • 支持邮件主题、落地页、CTA 按钮等多维度实验
  • 统计显著性自动计算，避免"感觉有效"的误判
Compliance

三级风控 + 内置合规引擎

广告法、PIPL、品牌规范、行业特定规则多层校验

🟢

L1 轻量

日常内容生产、话术生成
自动执行，违规标红建议修改

🟠

L2 标准

对外发布内容、活动海报
发布前弹窗确认，一键修正

🔴

L3 完整

金融/医疗/教育等受监管行业
法务审核流程，记录审计日志

校验内容覆盖

禁用词库（绝对化用语、虚假宣传）+ 广告法合规（最、第一、国家级等极限词）+ 个保法合规（个人信息处理规则）+ 品牌规范（Logo 使用、色彩、字体）+ 行业特定规则（金融广告、医疗器械等）
