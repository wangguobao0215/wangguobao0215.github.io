核心能力

正向/反向双模式报价
正向：从成本推导报价。反向：从客户目标价反推隐含毛利率，评估可行性并生成优化建议（提价/降材/延交/组合）。
📊
多行项报价引擎
支持 JSON 输入多产品组合，独立计算每行项（含行业特定参数），聚合整体报价，识别最弱利润项，统一折扣与审批。
🔍
成本穿透估算
三级费率 + 系数矩阵 + Wright 学习曲线 + 连续交期压缩系数。每项关键数据标注来源与信心等级（A/B/C）。
🛠
质保准备金与风险
质保期（12/18/24/36月）× 复杂度 × 工况的精准准备金模型。外汇风险对冲、材料锁价溢价纳入报价。
⚠
审批工作流与快照
三级审批路由（绿/黄/红）+ 7种特殊触发条件。不可变报价快照含 SHA-256 校验、差异对比、篡改检测。
🏢
ERP 集成
265行云星空字段映射，6个 MCP 工具完整 JSON Schema。AI Suite 增强：智能比价、产能排程、成本异常检测。
