PART 01

KnowledgeHub 架构设计

跨Skill中央知识广场的技术架构、数据模型与双向软协议

设计目标

KnowledgeHub（深知 · 知识中枢）构建一个跨Skill的中央知识广场，实现萃取、注册、检索、进化的完整闭环。

萃取
在九大Skill关键产出节点自动识别知识精华
注册
Markdown+Frontmatter为SSOT，SQLite为派生索引
检索
Skill工作时按需查询推送相关知识
双存储层 + 双向协议桥

字段约束
idKC-{CODE}-{YYYYMMDD}-{3位序列}，全局唯一
asset_typebest_practice / case_study / competitive_intel / playbook 等8种
confidenceA（高，案例+复用≥2）/ B（中，有案例）/ C（低，理论）
statusdraft / review / published / deprecated
SQLite Registry Schema
核心表结构
CREATE TABLE assets (
    id TEXT PRIMARY KEY,
    asset_type TEXT NOT NULL,
    title TEXT NOT NULL,
    summary TEXT DEFAULT '',
    source_skill TEXT NOT NULL,
    value_chain_stage TEXT NOT NULL,
    confidence TEXT CHECK(confidence IN ('A','B','C')),
    status TEXT DEFAULT 'published',
    reuse_count INTEGER DEFAULT 0,
    content_hash TEXT,
    file_path TEXT NOT NULL
);

CREATE TABLE feedback (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    asset_id TEXT NOT NULL,
    rating TEXT CHECK(rating IN ('useful','outdated','inaccurate')),
    comment TEXT DEFAULT ''
);

* reuse_log、audit_log、feedback 为历史表，rebuild时不被触碰

核心机制一览

ID生成策略

MAX-based序列 + INSERT OR FAIL重试，解决序列复用和并发碰撞问题。

KC-{STAGE_CODE}-{YYYYMMDD}-{3位序列}
示例：KC-SAL-20260428-001

Stage Code: RND/MKT/SAL/PSC/DEL/CSM/CRS

Confidence自动演化

基于复用次数和反馈比率动态调整资产质量等级。

规则条件效果
升级reuse≥3 且 useful≥75%C→B 或 B→A
降级outdated+inaccurate≥3A→B 或 B→C

Body-only Hash

仅对Frontmatter闭合线之后的正文计算MD5，确保reuse_count等字段更新时哈希不变。

安全重建模式

备份 → 填充临时表 → 完整性检查 → 原子切换，四段式安全重建。
