1选题引擎

热点抓取、内容拆解、多维评分、智能推荐

热点模式

  • 调用 news-aggregator-skill 抓取全网热点
  • 内容拆解：分析爆款文章的结构和情绪点
  • 生成选题卡片，多维度评分（时效性/受众匹配/竞争度/创作成本）
  • 用户选择后直接进入写作流程
  • 热点抓取失败时自动降级：备用源 → 本地缓存 → 人工输入

策划模式

  • 用 deep-research 调研方向
  • 生成 3-5 个专题方案供用户选择
  • 拆分为系列选题（每专题 3-8 篇）
  • 排定写作顺序和内容日历

2写作引擎

四种风格可选，素材收集、大纲生成、全文写作、润色自检

📚

深度风格

逻辑严密、数据支撑、引用规范，适合知乎长文和公众号干货

💖

故事风格

场景化叙事、情感共鸣、人物弧光，适合品牌故事和用户案例

⚡

犀利风格

观点鲜明、金句密集、节奏快，适合热点评论和行业洞察

🎈

轻松风格

口语化表达、emoji 点缀、互动感强，适合小红书和朋友圈

写作流程

分析选题 → 自动推荐风格（用户可改）→ 生成大纲（用户可调）→ 全文写作 → 润色自检 → 输出母版文章（Markdown）

3平台适配器

逐平台改写标题和内容，输出各平台专属版本

💬

微信公众号

主题排版、品牌题图底图、封面图适配

📰

今日头条

SEO 关键词优化、算法友好结构

📚

知乎

学术化风格、引用规范、长文分段

💖

小红书

Emoji 风格、短段落、图卡适配

📷

朋友圈

80 字精炼文案、配图建议

每个平台输出 3 个标题候选，用户可挑选或修改。内容改写保留核心观点，调整语气和结构以匹配平台调性。

4排版引擎 & 发布管线

自动排版配图、多平台发布草稿、知识库归档

排版引擎

  • 公众号：baoyu-post-to-wechat 主题排版，AI 生成封面与正文配图
  • 长文平台：baoyu-article-illustrator 自动配图建议
  • 小红书：baoyu-xhs-images 生成图卡系列

发布管线

  • 公众号 → API/浏览器自动发草稿箱
  • 头条 → Chrome CDP 自动化发草稿
  • 知乎/小红书 → 保存到本地输出目录
  • 朋友圈 → 生成 moments.md 手动复制

知识库归档

飞书知识库（lark-doc + lark-wiki）+ Obsidian 本地 vault 双归档。文章资产永久沉淀，支持全文检索和复用。

Use Cases

典型使用场景

🔥

热点追踪 → 爆文

→ 抓取热点 → 评分排序 → 用户选择 → 写作 → 适配全平台 → 发草稿
