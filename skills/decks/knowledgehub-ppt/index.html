双向协议
Skill 在知识结晶点强制萃取，在知识需求点强制推荐。不侵入 Skill 核心逻辑，开关一键切换。

The Flywheel Effect

知识飞轮

九大 Skill 在日常工作中持续产出知识。KnowledgeHub 萃取精华、注册索引、按需推送。 知识被复用得越多，置信度越高，推荐优先级越高，被复用的概率越大。

这不是一次性的知识沉淀，而是自增强的飞轮：产出 → 萃取 → 索引 → 推荐 → 复用 → 反馈 → 升级 → 更多产出。 每一圈都让知识库更厚、推荐更准、顾问更强。

"Obsidian 为存储层、SQLite 为索引层 —— 人可读可编辑，机可查可追踪。"
— Storage Philosophy
