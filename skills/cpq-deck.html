Why CPQ

制造业报价，为什么这么难？

⏱

耗时久

一份非标设备报价往往需要销售工程师耗费数小时甚至数天，反复核对 BOM、工艺、外协、税率，效率低下。

❓

缺数据

材料价格波动、设备产能占用、设计工时估算，关键数据分散在不同系统中，销售手里常常只有一张Excel。

⚠

风险高

合同里的延期罚金、质保期陷阱、出口认证要求，签完才发现踩坑，利润被风险条款吃掉。

🔄

难沉淀

每次报价都是"从零开始"，历史项目的成本偏差没有人系统复盘，同样的错误反复犯。

Solution

一个技能，覆盖报价全流程

Sloth-CPQ-Eido 运行在 QoderWork 平台上，通过自然语言理解客户需求，自动提取关键参数，基于行业知识库和成本模型，在几分钟内生成多方案报价对比。

核心价值

🏆 自然语言输入，自动识别四行业 📈 正向/反向/多行项，覆盖全场景 💡 不可变快照 + 24项回归测试保障

1需求解析与追问

从自然语言提取关键参数，自动识别行业，智能追问缺失项

行业自动识别

  • 提到"液压机/压力机/冶金设备" → 自动加载装备制造知识库
  • 提到"传动轴/箱体/钣金/CNC" → 自动加载通用机械加工知识库
  • 提到"PCB/SMT/贴装/元器件" → 自动加载电子制造知识库
  • 关键词模糊时主动询问确认，跨行业产品支持子系统分别处理

智能追问策略

  • 每次追问不超过 5 个问题，聚焦对成本和交期影响最大的参数
  • 优先追问：数量、交期、付款条件、特殊要求（防爆/出口/军工）
  • 检测到特殊风险项时立即发出预警（红色高亮）
  • 支持中英文混合输入，口语化描述也能准确解析
示例："客户需要一台 630 吨四柱液压机，工作台 1200x1200mm，西门子控制系统，力士乐液压，交期 90 天，帮我估个价。"

2成本穿透估算

按成本计算指南执行多维度拆解，每项关键数据标注来源

📊

材料成本

钢材/铜材/铝材/电子元器件，实时价格或缓存参考价，标注数据来源

👤

人工成本

基于历史项目工时数据库，按工序拆解加工、装配、调试工时

🏢

外协成本

热处理、表面处理、精密加工等外协工序，按供应商基准价估算

数据获取优先级（渐进式降级）

A
MCP 实时数据
B
CSV 模板数据
C
行业默认值

3交期可行性验证

从物料、产能、设计三个维度交叉验证，物理不可行时明确预警

📦

物料约束

长周期物料（进口液压元件、特种钢材）的采购货期是否超过客户要求的交付日期

⚙

产能约束

瓶颈设备（大型龙门铣、热处理炉）在目标周期内是否还有剩余产能

📐

设计约束

非标设计的工程周期是否挤压了制造时间，是否需要并行工程

验证结果输出

如果交期物理不可行，系统会明确警告并给出替代方案：延长交期 / 并行设计 / 外协关键工序 / 分批发货。每个方案都附带风险等级（High / Medium / Low）。

4合同条款风险扫描

在生成报价前扫描合同风险，量化财务影响并纳入报价

📜

延期罚金条款

按日/按周/按合同金额的百分比计算潜在罚金总额，建议预留风险准备金

🛠

质保期偏差

客户要求的质保期是否超出行业标准，超长质保的维护成本估算

💰

付款条件风险

预付款比例、尾款节点、信用证要求对现金流的影响分析

🌐

出口认证要求

CE / UL / ASME 等认证的时间成本和费用是否已计入报价

5多场景报价比选

输出至少 2 个方案，每个标注净利润交通灯和最大风险项

🚀

优先交期方案

外协关键工序 + 并行设计 + 加班赶工，利润让步换取交付速度

💰

优先利润方案

内部全自制 + 标准设计 + 常规交期，最大化净利润率

⚖

均衡方案

交期与利润的平衡点，推荐作为首选对外报价

盈亏交通灯

绿灯
净利润率 > 15%
黄灯
净利润率 8% ~ 15%
红灯
净利润率 < 8%

每个方案还包含：因子明细表（材料/复杂度/精度/批量因子）、假设与排除项、数据信心评级（A/B/C）。

6版本管理与偏差学习

保存报价快照，回写实际成本，持续优化报价准确性

报价版本管理

  • 同一客户/产品的多次报价自动保存为 V1、V2、V3...
  • 版本对比视图：参数差异、价格演变、客户反馈记录
  • 支持导出 Markdown 表格，直接粘贴到正式报价单

偏差学习闭环

  • 项目交付后输入实际成本，系统自动计算偏差率
  • 分析偏差根因：材料涨价 / 工时超支 / 返工报废
  • 自动更新对应产品类型的风险系数
  • 后续类似询价主动提示："上次液压机材料偏差 +12%，建议预留缓冲"

偏差学习数据存储

优先级：① MCP 后端数据库（推荐团队使用） → ② 本地 CSV 文件（`templates/project_history.csv`）→ ③ 会话内记忆。建议 3 人以上团队优先配置 MCP，避免本地数据冲突。

Automation

Python 自动化脚本

10个脚本覆盖报价全流程，让报价从" artisan "变成" engineer "

🖩

calculate_cost.py

成本穿透计算（正向/反向双模式），含学习曲线、质保准备金、外汇风险、材料锁价溢价

📊

generate_multi_item_quote.py

多行项报价引擎，JSON 输入多产品组合，聚合整体报价与统一折扣

🗃

parse_bom_csv.py

解析 BOM CSV（扁平/树形双模式），交叉匹配行业物料数据，自动识别缺失物料

📰

generate_quote_doc.py

生成专业 HTML 报价单文档，支持公司品牌、场景对比、审批状态、风险警告

📈

quote_analytics.py

历史报价分析仪表盘，5个子命令（summary/accuracy/pricing/risk/report），纯标准库

🔒

quote_snapshot.py

不可变报价快照，SHA-256 校验 + 差异对比 + 篡改检测，JSONL 存储格式

✅

validate_template.py

校验 CSV 文件格式合规性，提前发现数据问题

🔍

search_similar.py

搜索相似历史项目，引用历史报价参数和实际成本作为参考

质量保障

test_scripts.py 包含 24 项回归测试，覆盖正向 CLI（5）、反向 CLI（3）、工具函数（7）、多行项（3）、BOM（2）、模板校验（2）、相似搜索（2）。pytest 100% 通过。

Use Cases

典型使用场景

🏭

装备制造询价

"客户需要一台 630 吨四柱液压机，工作台 1200x1200mm，西门子控制系统，力士乐液压，交期 90 天，帮我估个价。"

→ 自动识别装备行业，追问付款/运输/安装要求，输出 3 个方案

⚙

机械加工询价

"有一批 40Cr 传动轴，直径 80mm 长 500mm，调质处理，公差 IT7，Ra0.8，数量 200 件，15 天交货，报个价。"

→ 自动识别机加行业，匹配加工工艺，验证 15 天可行性

💻

电子制造询价

"4 层 FR-4 板子，100x80mm，280 个贴片点，20 个插件，AOI+FCT 测试，首批 500 块，代采元器件，报价。"

→ 自动识别电子行业，核算 SMT + 测试 + 代采成本

🔄

偏差学习回写

"上次 630 吨液压机交付完了，实际材料成本 85 万，人工 32 万，外协 12 万，帮我做偏差分析。"

→ 对比报价估算 vs 实际成本，更新风险系数

Quick Start

快速开始

安装技能

cp -r Sloth-CPQ-Eido/ ~/.qoderwork/skills/sloth-cpq-eido/

将仓库根目录复制到 QoderWork 技能目录即可。如需 MCP 集成，参考 references/kingdee-mcp-integration.md。

准备数据（可选）

  • material_data.csv — 物料成本与货期
  • project_history.csv — 历史项目工时
  • workcenter_calendar.csv — 瓶颈设备产能
  • quote_version_log.csv — 报价版本记录

填入实际数据可将信心等级从 C 提升到 B，显著提高精度。
